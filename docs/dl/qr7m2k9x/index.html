Lead Routing & SLA Playbook

Download the editable routing matrix (CSV)

1. Why routing breaks

Most B2B teams lose leads not because volume is high, but because ownership is ambiguous the moment a lead arrives. The fix isn't a smarter CRM. It's an explicit routing matrix plus a hard SLA clock that something (not someone) enforces.

2. The routing matrix

Route on the smallest set of fields that actually predicts who should own the lead. In most B2B orgs that's region, company size band, product line, and inbound channel. Anything more granular decays fast as your org changes.

3. SLA clock logic (pseudocode, works for HubSpot, Salesforce, Zapier, n8n)

on lead.created:
    match = lookup_matrix(lead.region, lead.company_size, lead.product_line, lead.channel)
    assign(lead, match.owner_queue)
    start_timer(lead.id, duration = match.sla_minutes)

on timer.expired AND lead.status == "unworked":
    notify(match.escalation_target)
    reassign_if_no_response(after = match.sla_minutes * 2, target = "manager_pool")

on lead.status == "worked":
    cancel_timer(lead.id)
    log_time_to_first_touch(lead.id)

5. Metrics to track weekly

  • Time to first touch (TTFT): median and p90, per queue. This is the number that correlates with conversion, not volume.
  • SLA breach rate: % of leads where the timer expired before first touch. Target under 5%.
  • Reassignment rate: high values mean the matrix has the wrong owner mapped somewhere. Fix the matrix, not the people.
  • Coverage gaps: leads that matched no row. Should be 0; if not, add a catch-all row routing to a triage queue.

6. Rollout checklist

  1. Export the last 90 days of leads and tag each with region, size, product, channel.
  2. Build the matrix from actual distribution, not assumptions. Start with the 6 to 10 rows that cover 90% of volume, then add a catch-all.
  3. Implement the timer in whatever you already have (native CRM workflow, Zapier delay plus branch, or a small n8n flow). Don't wait for a "real" system.
  4. Turn on Slack escalation before you turn on reassignment. You want visibility before you automate consequences.
  5. Review breach rate weekly for 4 weeks, then monthly.

7. Common failure modes

  • Matrix too granular: routes break every reorg. Keep it to 4 dimensions max.
  • SLA timer with no escalation target: breaches pile up silently. Always name a person or pool, never "the team".
  • No catch-all row: leads that match nothing vanish into an unassigned queue forever.
  • Reassignment with no cooldown: leads ping-pong between reps. Add a minimum hold time before re-routing.
